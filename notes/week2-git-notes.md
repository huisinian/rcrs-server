# Week2 Git 学习笔记
## 一、Git 核心概念
1.  **工作区**：你电脑上看到的项目文件夹，存放你正在修改的文件。
2.  **暂存区**：临时存放你准备提交的修改，相当于“待提交清单”。
3.  **本地仓库**：电脑上的 Git 仓库，保存所有版本记录。
4.  **远程仓库**：GitHub 上的仓库，用来备份和协作。
## 二、常用 Git 命令
| 命令 | 作用 |
 |------|------|
| `git clone 仓库地址` | 把远程仓库下载到本地 |
| `git add .` | 把当前目录所有修改添加到暂存区 |
| `git commit -m "提交说明"` | 把暂存区的修改提交到本地仓库 |
| `git push origin 分支名` | 把本地分支的提交推送到远程仓库 |
| `git pull origin 分支名` | 把远程仓库的更新拉取到本地 |
| `git branch` | 查看/创建分支 |
| `git checkout 分支名` | 切换到指定分支 |
| `git merge 分支名` | 把指定分支合并到当前分支 |
| `git status` | 查看当前文件状态 |
| `git log` | 查看提交历史记录 |
| `git diff` | 查看文件修改前后的差异 |
## 三、.gitignore 文件
用来告诉 Git 哪些文件/文件夹不需要提交，比如日志文件、依赖包、配置密钥等，避免把没用的文件传到 GitHub 上。
