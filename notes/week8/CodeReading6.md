1：Agent 和 Server 之间用的是什么协议？数据是什么格式？
通信协议：TCP 协议（基于 Socket 长连接）
数据格式：Protobuf（Protocol Buffers）二进制结构化数据，由 .proto 文件定义结构，编译生成 RCRProto.java。
2：数据为什么要序列化？直接传 Java 对象行不行？
序列化的作用
将内存中的对象转为二进制字节流，可以通过网络传输、持久化保存；
跨语言、跨进程通信，两端只需要遵守同一份 proto 定义就能解析；
Protobuf 二进制体积小，传输效率高。
不能直接传输 Java 对象
Java 对象存在 JVM 堆内存中，只在本机进程有效；
对象包含地址引用，无法直接通过网络发送；
Java 序列化只能 Java 语言互通，不支持跨语言；
兼容性差，类结构改动容易导致解析失败。
